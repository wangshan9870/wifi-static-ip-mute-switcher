# Wi-Fi 固定 IP 与静音切换器

Wi-Fi 固定 IP 与静音切换器是一款原生 macOS 菜单栏应用：连接家庭 Wi-Fi 时，为 Mac 的 Wi-Fi 服务设置选定的 IPv4 地址；连接其他可识别的 Wi-Fi 时，恢复自动 DHCP。家庭网络按路由器硬件地址识别，不需要定位权限。它还可以在离家时自动静音内置扬声器，回家后恢复声音。

> 提供适用于 Apple Silicon 和 Intel Mac 的下载包，但尚未经过 Developer ID 签名与公证。首次使用时，请在家中绑定家庭网络并填写固定 IPv4 地址。未完成设置前，应用不会自动切换 IP 或控制扬声器。

## 开发背景

我在家习惯用 Mac 的内置扬声器外放。第二天早上带电脑到公司，如果忘了静音，网页视频或消息提示音可能突然响起来，挺尴尬的。与此同时，我在家需要一个稳定的局域网 IP，离开家后又希望恢复自动获取地址。

所以做了这个菜单栏工具：根据当前 Wi-Fi 的路由器判断是否在家。连接其他可识别的网络时，它恢复 DHCP 并静音内置扬声器；回到家后，再切回预设 IP，并取消扬声器静音。

## 功能

- 在家连接 Wi-Fi 后，点击「使用当前网络」绑定家庭路由器（Wi-Fi 网关的硬件地址）。不读取 Wi-Fi 名称，关闭定位服务也能工作。
- 设置家庭固定 IPv4 地址。应用使用 macOS 的「DHCP 手动地址」模式，让路由器继续提供网关等信息；其他已识别网络使用自动 DHCP。
- 订阅系统的网络和音频变化通知，不再定时轮询；连续两次读到同一路由器后再切换，避免网络短暂变化导致误操作。
- 可独立开启「离家自动静音内置扬声器」。非家庭网络、断网或无法识别路由器时保持内置扬声器静音；确认回家后取消静音一次，之后尊重手动静音。耳机及外接音频设备不受此功能控制。
- 支持登录时启动、立即检查、恢复 DHCP 并暂停。
- 设置窗口左侧和菜单栏可「检查更新」；应用每天最多自动检查一次 GitHub 最新版本，发现新版时在菜单栏和设置窗口提示，点击前往下载页。不会自动下载或安装。
- 原生操作窗口分为「当前状态」「家庭网络」「权限与启动」三个页面，显示实际状态；无效地址直接在设置页提示。

## 下载与安装

在 [Releases](https://github.com/wangshan9870/wifi-static-ip-mute-switcher/releases/latest) 下载 macOS DMG，打开后将应用拖到旁边的 Applications 文件夹，再从「应用程序」打开。安装包同时包含 Apple Silicon 和 Intel 架构，要求 macOS 13 或更新版本及带 Wi-Fi 的 Mac。

此下载包使用 ad-hoc 签名，**没有 Developer ID 签名或 Apple 公证**，因此 macOS 可能阻止首次打开。请确认下载来源为本仓库的 Releases，并通过 macOS「系统设置 → 隐私与安全性」中的提示手动允许打开；不要关闭系统的安全保护。安装网络助手时仍需单独授予管理员权限。

## 从源码构建

- macOS 13 或更新版本，带 Wi-Fi 的 Mac。
- Xcode 或 Xcode Command Line Tools，提供 `swiftc` 和 macOS SDK。

在项目目录执行：

```sh
./test.sh
./test-ui.sh
./build.sh
```

运行 `./package-dmg.sh` 可重新构建并生成 DMG 安装包和 SHA-256 校验文件，产物位于 `build/`。

`./test-ui.sh` 在本机 macOS 环境检查界面状态、未保存输入的保留和窗口释放，不执行网络或声音切换。界面使用原生 AppKit 控件；关闭窗口后释放界面对象，后台检测继续运行。

构建产物为 `build/Wi-Fi 固定 IP 与静音切换器.app`。将它复制到固定位置后再首次打开，例如：

```sh
mkdir -p "$HOME/Applications"
ditto 'build/Wi-Fi 固定 IP 与静音切换器.app' "$HOME/Applications/Wi-Fi 固定 IP 与静音切换器.app"
open "$HOME/Applications/Wi-Fi 固定 IP 与静音切换器.app"
```

应用使用 ad-hoc 签名，没有 Developer ID 公证。重新构建或移动应用后，macOS 可能要求重新确认权限。请通过系统提供的安全设置处理提示。

## 首次设置

1. 在家连接 Wi-Fi，在设置窗口点击「使用当前网络」自动填入路由器硬件地址（也可手动输入）；填写计划使用的固定 IPv4 地址，点击「保存家庭网络」。固定 IP 应处于家庭路由器网段，并在路由器的 DHCP 地址池中预留或排除。
2. 如果尚未安装网络助手，点击「安装网络助手」并按 macOS 提示完成管理员授权。修改固定 IP 时，「保存家庭网络」会请求授权并更新助手，无需再安装一次；只重新绑定路由器无需管理员授权。
3. 在菜单栏开启「自动切换」。需要开机后持续运行时，再开启「登录时启动」。首次运行时自动切换默认关闭；家庭网络未设置前，扬声器保护也不会执行。

设置页的「固定 IP」是本机希望使用的地址，不会替你修改路由器。程序会在首次使用目标地址前尝试 ping 检查占用；设备不回应 ping 仍可能已经占用该地址。

## 工作方式与权限

从 v1.4.0 起，macOS 关闭定位服务后会隐藏 SSID（`networksetup`、`ipconfig`、`system_profiler` 均只返回 `<redacted>` 或“未关联”），因此应用改为按 Wi-Fi 网关的硬件地址识别家庭网络。该地址由系统 configd 在 `State:/Network/Service/*/IPv4` 中发布（`ARPResolvedHardwareAddress`），读取不需要定位权限；尚未解析时回退到 `arp -n`，必要时先 ping 一次路由器。

应用通过 SystemConfiguration 订阅 `en0` 的链路、地址和网关变化，通过 CoreAudio 订阅音频设备列表及内置设备的静音、数据源变化，不再每 5 秒检查网络、每秒检查扬声器。收到通知后合并 1 秒内的变化再读取；读到一个网络后 2 秒再确认一次，连续两次相同才决定家庭或外出模式，也才在回家时取消静音。切换前重新核对路由器，执行后读取系统配置确认结果。失败后 60 秒再试；路由器暂未响应时以 3 秒起、最长 60 秒的间隔重试。唤醒后立即检查，另有每 5 分钟一次的兜底检查，防止遗漏通知；也可以在菜单栏点击「立即检查」。

无法识别路由器（未连接 Wi-Fi 或路由器未响应）时视为未知，不会据此切换 IP；已开启的扬声器保护仍会静音内置扬声器。外出时手动取消静音，会在音频变化通知后立即重新静音。

网络配置需要管理员权限。安装程序将受限助手放在 `/Library/PrivilegedHelperTools/cn.wangshan.home-ip`，并在 `/etc/sudoers.d/cn-wangshan-home-ip` 中仅允许当前用户免密码执行助手的 `home` 和 `dhcp` 两个操作。固定 IP 写入 root 所有的配置文件；助手只把它作为地址读取并再次校验，不执行任意命令，也不保存管理员密码。普通设置保存在当前用户的 macOS 偏好设置中。

程序只管理 Wi-Fi 服务的 IPv4 配置和内置扬声器静音状态，不修改 DNS、代理、IPv6、路由器或外接音频设备。

检查更新时，应用向 `api.github.com` 请求本仓库的最新 Release（启动 30 秒后，此后最多每 24 小时一次，或手动点击），不发送设备、网络或设置信息，也不保存缓存或 Cookie。只会打开本仓库的 Release 页面。

只在菜单栏运行时，常驻内存（活动监视器「内存」列，即 footprint）约 13 MB；打开设置窗口时约 30 MB，关闭后会把释放的内存还给系统。

## 限制

- 当前版本按一台家庭路由器工作，并使用 Mac 上名为 `Wi-Fi` 的网络服务及 `en0` 接口。服务名或接口不同的设备需要调整源码。
- 判断是否在家只依据 Wi-Fi 网关的硬件地址。更换路由器（或光猫改为路由模式）后需要重新绑定；从 v1.3 及更早版本升级时，旧的 Wi-Fi 名称设置不再使用，需要在家重新绑定一次。
- 完成家庭网络设置后，离家静音功能默认开启，独立于 IP 自动切换；应用退出后不会继续保护。回家、关闭该功能或退出时，不会恢复先前的音量数值。
- 强制结束应用、系统崩溃或断电时，无法保证自动恢复 DHCP。可在菜单栏选择「恢复 DHCP 并暂停」，或在 macOS 网络设置中手动改回 DHCP。

## 卸载

先在菜单栏关闭「登录时启动」，选择「恢复 DHCP 并暂停」，然后退出应用。在终端运行安装包内的卸载脚本：

```sh
sudo /bin/bash "$HOME/Applications/Wi-Fi 固定 IP 与静音切换器.app/Contents/Resources/uninstall-helper.sh"
```

如果安装在其他位置，请相应修改路径。脚本会恢复自动 DHCP，并移除网络助手、固定 IP 配置和 sudoers 规则。随后可删除应用。
